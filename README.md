# SE Practical 04: Result Function Testing

## Aim
To implement and test a result function using Python.

## Files
- `a.py` – Contains the result function.
- `manua_test.py` – Performs manual testing.
- `test_result.py` – Performs automated unit testing using Python's unittest module.

## Result Rules
- Marks below 40: Fail
- Marks from 40 to 100: Pass
- Marks below 0 or above 100: Invalid

## How to Run
Manual testing:
`python manua_test.py`

Automated testing:
`python -m unittest test_result.py -v`

## Conclusion
The result function was tested using valid and invalid marks through manual and automated testing.
